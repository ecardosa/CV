# CV

This project is part of the Hypermedia course and consists of designing and developing a personal Curriculum Vitae (CV) website.  
The objective is to create a well-structured and visually coherent single-page site that presents my skills, experience, and projects in an organized and accessible way.

Website:
[Link to the website](https://ecardosa.github.io/CV/)

## Design Concept

The website follows a minimalist dark theme, focused on simplicity and readability.  
The color palette is mainly black, combined with subtle violet accents to create a professional and elegant atmosphere. The design avoids unnecessary decoration, allowing the user’s attention to stay on the content.

Each section — Hero, Skills, Experience, Projects, and Contact — is clearly defined and structured to ensure a smooth and intuitive browsing experience.

Figma design:  
[View the design on Figma](https://www.figma.com/design/rK2XJcrhgUxFe3eAwd792D/Untitled?node-id=0-1&t=ZAoKK4DvR53W5sYE-1)  

## Features

- Responsive single-page layout.
- Fixed navigation bar for direct access to each section.
- Animated gradient background in the hero section.
- Organized presentation of skills and technologies.
- Project cards with links to GitHub repositories.
- Contact form integrated through Formspree.
- Smooth transitions and scrolling behavior.

## Technologies Used

- HTML5  
- CSS3 (Flexbox, Animations, Media Queries)  
- Font Awesome for icons  
- Google Fonts (Inter & Montserrat)
